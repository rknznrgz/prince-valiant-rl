# Command-line tools

Use `python run.py --list` from the repository root to see supported commands, and `python run.py COMMAND --help` for arguments.

This folder contains selected data-preparation, training, evaluation, and model-inspection entry points. Files beginning with `_` and shared helper modules support those commands and are not separate advertised workflows.

See [setup and commands](../docs/SETUP.md) before running tools. Preparation and evaluation may require external assets or execute the emulator; choose fresh output paths.
